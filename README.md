# 우리집 대시보드

아이들 케어 · 내 업무 · 사업(에이치엠유통) · 집 가계부를 한 화면에 모은 가족 대시보드입니다.
설치 없이 웹 주소로 열리고, 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

- **주소**: https://aram0413-hub.github.io/aram-dashboard/
- **저장 방식**: 입력한 내용은 각 기기의 브라우저(`localStorage`)에 자동 저장됩니다.

## 탭 구성

| 탭 | 내용 |
| --- | --- |
| 🏠 대시보드 | 출발 시간 카운트다운, 전체 진행률, 아이들·업무·사업·가계부 요약 |
| 🧒 아이들 케어 | 초5 / 초3 전환·나란히 보기, 등원 준비·하원 루틴 카드(단계 추가·수정·삭제) |
| 💼 내 업무 | 오늘 / 이번 주 할 일, 중요도 태그, 빠른 메모 |
| 📦 에이치엠유통 | 월별 매출·매입 현황(연간 KPI·월별 표·거래처 요약·부가세 신고 기록), 사업 고정지출, 사업 할 일·일정, 사업 메모 |
| 💰 집 가계부 | 월 예산, 수입·지출 기록, 분류별 합계 막대, 내역 목록 |

## 상단

- 한국 시간 기준 실시간 시계와 날짜
- 통영 날씨(현재·체감·습도·바람), 7일 예보, 미세먼지 등급
  (Open-Meteo Forecast API · Air Quality API, 브라우저에서 직접 조회)

## 매출·매입 현황 (에이치엠유통 탭)

홈택스 등에서 정리한 월별 매출·매입 JSON 파일을 **📥 매출·매입 불러오기** 로 읽으면
연간 KPI 4칸(매출·세금계산서 매입·사업용카드 매입·차액), 월별 표(PC)·월별 카드(모바일),
월별 막대 비교, 매출처·매입처 요약, 부가세 신고 기록, 챙길 메모가 표시됩니다.

- **＋ 월 입력 / 월 이름 클릭**: 그 달 매출·매입을 직접 입력·수정(세액은 공급가액의 10%로 자동 채움)
- **⬇️ 내보내기**: 입력한 매출·매입을 JSON 파일로 백업
- 불러오기는 기존 루틴·고정지출·가계부를 건드리지 않고 매출 기록만 더하며, 이미 있는 달은 건너뜁니다(필요하면 덮어쓰기 선택).
- **실제 금액·거래처·사업자번호는 저장소(코드)에 넣지 않았습니다.** 파일을 불러온 내용은 그 기기 브라우저에만 저장됩니다.

## 데이터 백업

⚙️ 설정에서

- **파일로 내보내기**: `우리집-대시보드-백업-YYYY-MM-DD.json`
- **파일 가져오기**: 다른 기기에서 백업 파일을 그대로 불러오기
- **초기화**: 처음 상태로 되돌리기

기기마다 저장소가 따로라서, 여러 기기에서 같은 내용을 보려면 한 기기에서 내보낸 파일을 다른 기기에서 가져오면 됩니다.

## 참고

- 이 저장소는 공개 저장소입니다. 개인정보(실명, 연락처, 주소, 정확한 금액, 계좌·카드 내역 등)는 코드에 넣지 않았습니다.
  아이 이름표·예산 같은 값은 설정 화면에서 입력하며, 그 값은 인터넷에 올라가지 않고 각 기기 브라우저에만 저장됩니다.
